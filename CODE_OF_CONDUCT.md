# Code of Conduct

Play Together is intended to be a professional, constructive open-source project.

Contributors are expected to:

- discuss ideas and code without personal attacks or harassment;
- give specific, technical feedback rather than dismissive commentary;
- respect different experience levels, backgrounds, and communication styles;
- avoid discriminatory, threatening, sexual, or intentionally disruptive behavior;
- protect private information and report security issues through the private security process.

Maintainers may edit or remove abusive content, close discussions that repeatedly violate these expectations, or restrict participation when necessary to protect the project and its contributors.

If conduct needs maintainer attention, use a private repository contact channel rather than escalating the issue publicly.
