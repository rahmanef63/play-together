# Turbo Circuit asset policy

Turbo Circuit 0.9.0+ uses procedural Three.js geometry, deterministic Canvas-derived surface maps, CSS/SVG HUD presentation, and Web Audio synthesis for the live cartridge. No runtime raster vehicle atlas is required.

`assets/source/generated-2026-08-31/` is archival source/reference artwork from an earlier visual exploration. It is not copied into new immutable releases unless a future release explicitly declares a reviewed runtime asset manifest.

Historical immutable releases retain their own packaged assets under `releases/game-cdn/`; do not delete or rewrite those bytes.
